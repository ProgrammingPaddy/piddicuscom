    How this works

    Every entry on the menu is a folder dropped into projects/. Some are written here directly; others live in their own repository and are copied in at a pinned commit. A small script scans that folder and writes the menu you see above.

    No framework, no bundler. Each project is plain HTML served exactly as it was written.
